个人写作技法手册。每条技法一个文件，结构统一，方便查阅、增补和改稿时自查。

## 分类说明

| 分类 | 管什么 |
|---|---|
| 句法 | 句子内部：长短、语序、修饰、用词 |
| 结构 | 段落与篇章：开头、结尾、转折、详略 |
| 描写 | 场景、动作、感官细节 |
| 人物 | 塑造、动机、心理 |
| 对话 | 对白写法、潜台词 |
| 论述 | 说理、论证、观点表达 |
| 修改 | 改稿流程与方法 |

可以按需新增分类，新增后补到上表。

## 新增技法的流程

1. 复制 [`_template.md`](_template.md) 到 `techniques/`，命名为 `NN-技法名.md`，编号按顺序递增，两位数。
2. 按模板九个部分加附录逐项填写。暂时写不出的部分保留标题，内容写"（待补充）"，不要删掉。
3. 在上面的目录表里加一行。
4. 如果和已有技法相关，在双方的"九、相关技法"里互相登记。

## 条目结构（固定九部分＋附录）

| 部分 | 回答的问题 |
|---|---|
| 口诀＋信息表 | 一句话怎么记？属于哪类、适合什么文体、出自哪里？ |
| 一、定义 | 这条技法是什么？ |
| 二、为什么有效 | 背后的原理是什么？ |
| 三、怎么用 | 具体怎么操作？ |
| 四、用在哪里 | 最适合什么场景？ |
| 五、例子 | 改前、改后、分析 |
| 六、注意事项 | 哪些地方不该用？常见误用有哪些？ |
| 七、自查清单 | 改稿时逐项检查什么？ |
| 八、练习方法 | 怎么刻意练习？ |
| 九、相关技法 | 和哪些技法互补或冲突？ |
| 附：更新记录 | 什么时候收录、什么时候修改过？ |
