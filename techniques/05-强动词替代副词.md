# 技法 05：强动词替代副词

> **口诀**：让动词干活，副词靠边。一个准确的动词，胜过一串"××地"。

| 项目 | 内容 |
|---|---|
| 分类 | 句法 |
| 适用文体 | 叙事、描写、散文；论述和公文也适用于"去掉虚化动词"的部分 |
| 标签 | 动词、副词、炼字、用词精确、虚化动词、名词化、对话标签 |
| 来源 | 技法 01 的延伸；斯蒂芬·金《写作这回事》（"通往地狱的路是用副词铺成的"）；中国古典诗文的"炼字"传统；奇异果整理 |
| 收录日期 | 2026-11-17 |

## 一、定义

**弱动词＋副词**：用一个笼统的动词，再靠副词补充方式、力度和情绪。
> 他很快地走进房间。她偷偷地看了他一眼。他生气地大声说："出去！"

**强动词**：用一个本身就包含了方式、力度或情绪的具体动词，副词就不需要了。
> 他冲进房间。她瞟了他一眼。他吼："出去！"

这条技法要求：**看到"××地＋笼统动词"，先找有没有一个更准确的动词能独自完成任务。** 同理，"进行了讨论""做出了决定"这类用虚化动词撑起来的结构，也还原成"讨论""决定"。

## 二、为什么有效

1. **更精确**："走"可以是快、慢、犹豫、得意，"踱""蹿""挪""闯"各自只有一种样子，读者脑中的画面是确定的。
2. **更经济**：一个字顶三四个字，句子短了，节奏也快了（见技法 01）。
3. **更有画面**：副词是作者的说明，强动词是读者看得见的动作。"生气地说"是告诉，"吼"是展示（见技法 03）。
4. **副词往往是在补救**：需要副词来撑，常常说明动词选得不够准。斯蒂芬·金在《写作这回事》里说"通往地狱的路是用副词铺成的"，就是这个意思。
5. **中文动词本来就丰富**：单单"看"就有瞥、瞟、瞄、盯、瞪、扫、望、瞧、打量、端详、凝视……还有"推开""摔碎""扯断"这样的动补结构，能把动作和结果一起写出来。中文写作的"炼字"传统，炼的大多是动词。

## 三、怎么用

1. **圈出"××地"**：把稿子里所有方式、情态类副词（"很快地""轻轻地""生气地""偷偷地"）圈出来。
2. **问一句"能不能用一个动词说"**：把"副词＋动词"合起来想，有没有一个现成的动词正好表达这个意思？
3. **按语义场找词**：先确定动作的大类（看、走、说、拿……），再在这一类里挑最贴切的那个（见下方词表）。
4. **试试动补结构**：动作有结果时，用"动词＋结果"一起写，比如"推开""踢翻""撕碎""喊哑"。
5. **删掉虚化动词**："进行""做出""给予""加以"后面跟着动词性名词的，还原成动词本身。
6. **检查有没有叠加**：换上强动词后，把原来的副词删掉，不要写成"狠狠地摔"。
7. **出声读**：确认新动词的语气、色彩和上下文是否协调。

| 走 | 踱、蹿、窜、冲、闯、挪、蹭、溜、迈、跨、蹒跚、踉跄 |
| 说 | 嘀咕、嘟囔、念叨、吼、喝、嚷、喊、抢白、顶嘴、低语、搭腔 |
| 拿 | 抓、攥、捏、拈、拎、提、捧、托、端、揣、夺、抄起 |
| 放 | 搁、撂、扔、丢、甩、摔、码、摆、塞、按 |

## 四、用在哪里

- **动作描写**：打斗、追逐、劳动，动词直接决定画面的速度和力度。
- **人物刻画**：一个人习惯用什么动作，就是什么性格。总是"踱"的人和总是"蹿"的人不一样。
- **情绪场面**：用动作承载情绪，代替"愤怒地""伤心地"。
- **改稿压缩**：篇幅需要压缩时，副词往往是最先能删的部分。
- **工作文档**：删掉"进行""做出"这类虚化动词，句子立刻干净。

## 五、例子

### 例 1：方式

- ❌ **改前**：他很快地走进房间。
- ✅ **改后**：他冲进房间。（或：他闯进房间。）
- **分析**："冲"和"闯"都快，但"闯"还带着不请自来、不顾阻拦的意思。选哪个取决于你想让读者看到什么，这就是强动词的精确之处。

### 例 2：力度与情绪

- ❌ **改前**：他生气地大声说："出去！"
- ✅ **改后**：他吼："出去！"
- **分析**："生气地""大声"两个修饰，一个"吼"全包了。

### 例 3：小心翼翼的动作

- ❌ **改前**：她轻轻地、小心地拿起那只杯子。
- ✅ **改后**：她把那只杯子捧了起来。
- **分析**："捧"用两只手、向上托，本身就带着珍视和小心。

### 例 4：偷看

- ❌ **改前**：她偷偷地看了他一眼。
- ✅ **改后**：她瞟了他一眼。
- **分析**："瞟"是斜着眼、很快地看，"偷偷"的意思已经在里面了。

### 例 5：虚化动词

- ❌ **改前**：双方就合作问题进行了深入的讨论，并做出了延期的决定。
- ✅ **改后**：双方深入讨论了合作问题，决定延期。
- **分析**："进行讨论""做出决定"是公文里最常见的虚胖。还原成动词，句子短了三分之一，意思一点没少。

### 名家参考

- **王安石"春风又绿江南岸"**：据洪迈《容斋续笔》记载，"绿"字先后试过"到""过""入""满"等十几个字，最后才定下来。"绿"把形容词用作动词，写出了春风吹过、江南一片转绿的过程。
- **贾岛"僧敲月下门"**："推"还是"敲"，贾岛反复斟酌，这就是"推敲"一词的来历。"敲"有声音，衬出月夜的静，这是动词选择带来的意境差别。
- **鲁迅《孔乙己》**："排出九文大钱"和"摸出四文大钱"，一个"排"、一个"摸"，写尽了人物处境的变化（见技法 03）。

## 六、注意事项

### 不该用的地方

- **副词提供了动词给不了的信息时**："他悄悄地推开门"，"悄悄"说的是声音和意图，没有哪个动词能独自表达，这种副词该留。
- **时间、程度、范围、否定类副词**：已经、仍然、大约、仅、都、不……这些不是本条要处理的对象，说明文和论述里尤其不能乱删，删了意思就变了。
- **对话标签**：引出对话时，"说"几乎是隐形的，读者的注意力会留在对话本身。每一句都换成"咆哮""嗔怪""嘟囔"，反而喧宾夺主，偶尔点一下就够。
- **人物的说话方式**：人物台词里的副词反映人物的口语习惯，不必按叙述语言的标准去改。

### 常见误用

- **生僻字堆砌**：为了"强"而用踯躅、逡巡、趔趄、睥睨，读者一路查字典，节奏全毁。强动词要准，不是要偏。
- **动词用力过猛**：人物每次说话都"吼"，每次走路都"冲"，强动词就成了噪音。力度要和情境匹配。
- **强动词＋副词叠加**："狠狠地摔""死死地攥紧"，动词已经够力，副词是多余的。
- **色彩或语体不搭**：古雅的动词放进现代口语场景，或者口语动词放进正式文本，会显得别扭。
- **为换而换**：同一个动作反复出现时，不必每次都换一个同义词。该用"说"的地方就用"说"。

## 七、自查清单

- [ ] 稿子里有多少"××地＋动词"？每一个能不能换成一个强动词？
- [ ] 换上强动词以后，原来的副词删掉了吗？
- [ ] 新动词的意思是不是准确，有没有带进不想要的附加含义？
- [ ] 有没有为了"强"而用了生僻字？
- [ ] 力度大的动词是不是用得太密？
- [ ] 对话标签是不是花样太多，抢了对话本身的戏？
- [ ] 有没有"进行""做出""给予""加以"这类虚化动词可以删？
- [ ] 删副词时，有没有误删时间、程度、范围、否定类副词？

## 八、练习方法

1. **语义场扩充**：选一个基础动词（看、走、拿、说），尽量写出它的同类动词，每个造一个句子，体会差别，把好用的补进上面的词表。
2. **删副词练习**：拿一段自己写的文字，把方式类副词全部删掉，再逐一判断：哪些要换成强动词，哪些必须补回副词。
3. **炼字练习**：找一句名家名句，把关键动词挖空，自己填五个候选，再和原文对照。
4. **公文瘦身**：找一份工作文档，把"进行""做出""给予"全部还原成动词，比较改前改后的字数。
