# 技法 04：句子往后长

> **口诀**：先让读者知道"说的是什么"，再告诉他"它是什么样的"。句子可以长，但要往后长，不要往前长。

## 一、定义

- **往前长**：在句子主干（核心名词或核心动作）**前面**堆修饰语。读者要读很久才看到主干。
- **往后长**：主干**先**出现，细节用分句、补语或独立短句一节一节**接在后面**。

这条技法要求：**一个句子需要承载较多信息时，让主干先出来，把细节往后放。**

> ❌ 往前长：我想起那个在外婆家的、种着一棵每年夏天都结满枣子的老枣树的院子。
>
> ✅ 往后长：我想起外婆家的院子，院里有棵老枣树，每年夏天都结满枣子。

## 二、为什么有效

1. **读者是从左往右读的**：修饰语在前，读者就得先把一堆细节记在脑子里，却还不知道这些细节在说谁，要等到最后一个字才能拼起来，拼完还得回头再理解一遍。
2. **每读一节，画面就完整一次**：往后长的句子，读到第一个逗号时主干已经清楚了，后面只是在已有的画面上添东西，读者手里不用攥任何零件。
3. **中文修饰语天然前置**：中文的定语、状语都放在中心词前面，所以修饰一多就容易"往前长"。英文有后置的定语从句，天然往后长；直译成中文就变成一串"……的……的"，这就是欧化句（翻译腔）的主要来源。
4. **流水句是中文本来的办法**：用逗号把一个长意思切成几小节，一节接一节往后流，每节都短，整句再长也不累。

> **比方**：往前长，像把一堆行李推在火车头前面，越推越费劲；往后长，像在火车头后面挂车厢，挂多少节火车头都照样往前跑。

## 三、怎么用

1. **找主干**：先确定这句话的核心是什么，即"谁＋做了什么"或"什么东西"。
2. **数前置修饰**：主干前面有几个"的"、几个"地"？超过一个，或者某一个特别长，就要动手。
3. **选一种改法**：
   - **长定语 → 后面的分句**：把"……的"拆出来，放在主干后面，用逗号接上。
   - **长状语 → 后面的补语或分句**：把"……地"挪到动词后面，比如"跑得飞快""头也不回"。
   - **长主语 → 先拆出来，再用代词接**：先把主语的背景单独说一句，再用"他""它""这""那"接上后半句。
   - **"用一种……的"结构 → 先说动作，再单独描写**：比如"他说了一句话。声音很低……"
4. **检查主语有没有乱换**：往后接分句时，中间换了主语的地方最好断句，免得读者搞不清是谁在做事。
5. **出声读一遍**：读的时候不用憋气、不用回头重读，就改对了。

## 四、用在哪里

- **描写人物、场景、物件**：细节多、修饰多的地方最容易往前长。
- **介绍复杂背景的句子**：尤其是带长主语的句子，比如"那个……的人""这项……的政策"。
- **翻译或者改写外文材料**：英文从句直译过来的地方，是往前长的重灾区。
- **工作文档、说明文**：一般的说明性文字同样适用，能显著提高可读性。

## 五、例子

### 例 1：长定语

- ❌ **改前**：这是一个在城市边缘的、破旧的、早已被人遗忘的车站。
- ✅ **改后**：这是个车站，在城市边上，很破，早没人记得了。
- **分析**：读者先拿到"车站"这个核心，再一层层加细节，像镜头慢慢推近。

### 例 2：长状语

- ❌ **改前**：她飞快地、头也不回地、像逃命一样地跑了。
- ✅ **改后**：她跑了，跑得飞快，头也不回，像在逃命。
- **分析**：动作"跑了"先出来，读者马上知道发生了什么，修饰变成补语和分句接在后面，节奏也快了。

### 例 3：长主语

- ❌ **改前**：那个昨天在会上第一个站出来反对削减预算的副总今天辞职了。
- ✅ **改后**：昨天开会，有个副总第一个站出来反对削减预算。今天他辞职了。
- **分析**：主语太长，读者要等很久才看到"辞职了"。先把背景说完，再用"他"接上，句子等于重新起了个头。这一种最容易被忽略。

### 例 4："用一种……的"

- ❌ **改前**：他用一种近乎绝望的、带着颤抖的声音低低地说了一句话。
- ✅ **改后**：他说了一句话。声音很低，在发抖，近乎绝望。
- **分析**："用一种……的声音"是典型的欧化结构。拆开以后主干先行，每个细节都有自己的位置和分量。

### 例 5：翻译腔

- 英文：the courtyard that had an old jujube tree which bore fruit every summer
- ❌ **直译**：那个有一棵每年夏天都结果的老枣树的院子
- ✅ **改后**：那个院子，里面有棵老枣树，每年夏天都结果。
- **分析**：英文的核心词 courtyard 在前，从句在后，是往后长的；直译把从句全搬到前面，变成了往前长。改法就是还原英文本来的顺序，用中文流水句接上。

## 六、注意事项

### 不该用的地方

- **短的前置修饰不用改**："一个破车站""她飞快地跑了"完全正常。只有超过一个、或者很长的前置修饰才需要往后挪。
- **故意制造悬念**：想让读者读到最后一个字才知道答案时，可以有意往前长。但这是有意为之，不是习惯。
- **法律、合同、公文**：这类文字要求限定精确、不能产生歧义，前置长定语有时避免不了，可读性要让位于准确性。
- **固定说法和术语**："中华人民共和国国家发展和改革委员会"这类专名不能拆。

### 常见误用

- **往后长得没有尽头**：一个流水句接了七八节，中间换了好几次主语，读者照样会迷路。该断句时就断句。
- **拆完以后指代不清**：长主语拆开后，后半句的"他""它"指谁要明确，前面出现了两个人时尤其要小心。
- **拆成一堆零碎短句**：往后长不等于全部切成短句（见技法 02），节在逗号上、句子还是一个整体，才是流水句。
- **把必要的限定拆丢了**：有些定语是用来区分对象的（"穿红衣服的那个人"），拆的时候不要把区分信息弄没了。

## 七、自查清单

- [ ] 主干前面有没有超过一个"的"或"地"？
- [ ] 有没有很长的主语，读者要等很久才看到谓语？
- [ ] 有没有"用一种……的""在……的情况下"之类的结构？
- [ ] 从外文翻译或改写的句子，有没有直译成一串"……的……的"？
- [ ] 往后接的分句里，有没有换了主语却没断句的地方？
- [ ] 拆开以后，代词指代是不是清楚？
- [ ] 读的时候需不需要憋气、需不需要回头重读？

## 八、练习方法

1. **"的"字计数**：拿一段自己写的文字，把每句主干前面的"的""地"圈出来，超过一个的逐句改写。
2. **长主语专项**：找出所有"那个……的人""这个……的问题"结构，按"先拆背景、再用代词接"的方法改写。
3. **翻译对照**：找一段英文原文和它的直译本，把直译本里往前长的句子改成流水句，再和好的译本对照。
4. **名家抄写**：抄汪曾祺、沈从文的描写段落，留意他们怎么用逗号把长意思切成小节，主干放在哪里。
