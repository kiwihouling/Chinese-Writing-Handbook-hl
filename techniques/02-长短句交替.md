# 技法 02：长短句交替

> **口诀**：句子的形状贴着内容的形状。长句铺，短句打；要长，就往后长。

## 一、定义

根据内容需要来决定句子长短，而不是一律求短或者一律求长：

1. **长短交替**：长句负责铺垫和流动，短句负责转折和冲击，两者配合着用，节奏才有起伏。
2. **长句有它自己的位置**：回忆、意识流、慢慢涌上来的情绪，适合用长句的绵延感。
3. **好的长句往后长**：主干在前，细节一节一节往后接（中文"流水句"），不往主干前面堆修饰语。（原理和完整改法见 [技法 04：句子往后长](04-句子往后长.md)）
4. **论述靠复句**：说理时句子之间的逻辑关系本身就是论证，不能切碎；论述的"一事"单位是段落，不是句子。

## 二、为什么有效

1. **冲击力是对比出来的**：短句有力，是因为它打断了原来的节奏。前面先有流动，后面的停顿才显得狠。句句都是短句，句句都是重音，也就没有重音了。
2. **句子之间的关系需要载体**：短句把信息切开，同时也切掉了句子之间的因果、转折和伴随关系。全是短句，读者拿到的是一堆零件（"电报感"）。
3. **句式模拟心理状态**：回忆和意识流是连绵的，一个念头牵出另一个念头。长句一口气不换气，读的过程本身就在模拟这种状态。
4. **流水句符合中文习惯**：中文长句靠逗号一节节往前推，每节都短，读者随时知道主干是什么，所以句子长也不累。前置修饰太长，读者就得憋着气等主干出现。
5. **论证即关系**："虽然……但……所以……"不是装饰，而是作者的推理过程，删掉就等于删掉了论证。

## 三、怎么用

1. **先定段落的情绪速度**：这一段是要快（冲突、意外），慢（回忆、抒情），还是讲道理（论述）？
2. **快段落**：以短句为主，中间夹一两个稍长的句子换气，避免变成清单。
3. **慢段落**：以长句为主，用逗号把细节往后串；结尾可以用一个短句收住，形成落差。
4. **制造冲击**：想让某个信息砸下来时，前面先用一两个长句铺垫，再用一个极短的句子单独成段。
5. **检查长句的方向**：长句写完问一句"主干在不在前面？"如果在后面，就把前置修饰拆开挪到后面。
6. **论述段落**：段首写中心句，后面用复句展开，保留"因为、但是、所以、除非"这些关联词；一句话里关联词嵌套不超过两层。
7. **出声读**：一段读下来，节奏应该有快有慢；从头到尾一个速度，就需要调整。

## 四、用在哪里

| 场景 | 句子策略 | 原因 |
|---|---|---|
| 动作、冲突、转折 | 短句为主 | 制造速度和冲击 |
| 回忆、抒情、意识流 | 长句为主，往后长 | 模拟思绪的绵延 |
| 一般叙事 | 长短交替 | 有流动，也有重音 |
| 悬念揭晓、情节突变 | 长句铺垫 + 短句收尾 | 靠落差制造冲击 |
| 论述说理 | 复句为主，一段一个论点 | 逻辑关系就是论证本身 |

## 五、例子

### 例 1：全是短句的"电报感"

- ❌ **改前**：他起床。拉开窗帘。下雨了。他坐下。泡了咖啡。没喝。他看着窗外。雨很大。他想起她。
- ✅ **改后**：他起床拉开窗帘，外面在下雨。咖啡泡好了，他没喝，只是坐着看窗外，雨越下越大。他想起了她。
- **分析**：改前每句一样重，读者分不清重点。改后把过场动作并进较长的句子，最后"他想起了她"单独留短，成为全段的重音。

### 例 2：长句铺垫，短句冲击

- ✅ **示范**：
  > 他在窗前坐了很久，咖啡从烫手放到凉透，雨一直没停，楼下的车灯一盏接一盏划过去，他想起那年她站在站台上回头的样子，想了很多遍，每一遍都比上一遍更模糊。
  >
  > 电话响了。
- **分析**：长句把情绪慢慢铺开，读者被带进一种缓慢的状态；"电话响了"四个字单独成段，突然切进来。要是前面也是短句，这四个字就没有冲击力了。

### 例 3：回忆用长句

- ❌ **改前**：我想起外婆家。院子里有棵枣树。夏天很热。她总在树下摇扇子。
- ✅ **改后**：我想起外婆家的院子，那棵枣树，夏天热得连蝉都叫得有气无力，她就坐在树底下摇着蒲扇，一下一下，摇到我睡着，又摇到我醒来，好像那个下午永远不会结束似的。
- **分析**：改前像在汇报，改后才像在回忆。"一下一下""摇到我睡着，又摇到我醒来"，句子本身就在模仿那个漫长的下午。

### 例 4：坏长句与好长句

- ❌ **往前长**：我想起那个在外婆家的、种着一棵每年夏天都结满枣子的老枣树的院子。
- ✅ **往后长**：我想起外婆家的院子，院里有棵老枣树，每年夏天都结满枣子。
- **分析**：两句信息量差不多，前一句要憋着气读到最后才知道说的是"院子"；后一句主干先出来，细节往后接，读起来是顺的。**长句可以长，但要往后长。**更多改法见[技法 04](04-句子往后长.md)。

### 例 5：论述不能切碎

- ❌ **改前**：这个方案成本低。风险集中在上线初期。应该先小范围试点。数据稳定后再推广。
- ✅ **改后**：这个方案虽然成本低，但风险集中在上线初期，所以应该先小范围试点，等数据稳定后再推广。
- **分析**：改前每句都对，但"成本低"和"风险高"是什么关系、为什么要试点，读者只能自己猜。"虽然……但……所以"就是作者的推理。

### 名家参考

- **普鲁斯特**《追忆似水年华》：玛德莱娜小蛋糕段落，一口茶和蛋糕的味道牵出整个童年的贡布雷。句子常常长达半页，模拟记忆层层展开、没有尽头的样子。
- **张爱玲**《金锁记》开头：写三十年前的月亮，"像朵云轩信笺上落了一滴泪珠，陈旧而迷糊"，再写"隔着三十年的辛苦路往回看，再好的月色也不免带点凄凉"。苍凉感是在层层递进的长句里慢慢渗出来的。

## 六、注意事项

### 不该用的地方

- **紧张的动作场面不要用长句**：打斗、追逐时插进一个绵延的长句，会让节奏突然塌下来。确实需要放慢镜头（比如慢动作效果）的情况除外。
- **说明文、操作步骤不追求节奏起伏**：这类文字以清晰为第一要务，一步一句即可。
- **不要为了"交替"而交替**：长短要跟着内容走，机械地一长一短也是一种单调。

### 常见误用

- **把"长句"写成"前置修饰堆砌"**：句子长不是问题，主干被埋在后面才是问题。
- **长句里塞了好几个主语**：一个流水句中间换了几次主语，读者会搞不清是谁在做事。换主语的地方最好断句。
- **论述里关联词嵌套过深**："虽然……但是由于……因此尽管……"这种层层嵌套，读者跟不上，应该拆成几句，每句保留一层逻辑关系。
- **抒情长句没有收束**：一段长句接着一段长句，从头绵延到尾，读者会疲倦。适时用一个短句收住。

## 七、自查清单

- [ ] 这一段的情绪速度是快、慢，还是说理？句子长短跟它匹配吗？
- [ ] 全段是不是一个速度从头走到尾？
- [ ] 最想让读者记住的那句话，是不是足够短、足够孤立？
- [ ] 长句的主干是不是在前面？有没有往前堆修饰？
- [ ] 一个长句里有没有换好几次主语？
- [ ] 论述段落的关联词是不是还在？有没有被切成互不相干的短句？
- [ ] 关联词有没有嵌套超过两层？
- [ ] 大声读一遍，节奏有没有起伏？

## 八、练习方法

1. **节奏标记**：拿一段自己写的文字，在每句后面标上字数，画成折线图。线是平的，就说明节奏单调。
2. **一段两写**：同一个场景分别用"全短句"和"长短交替"各写一遍，对比读，体会冲击力从哪里来。
3. **抄写名家长句**：抄普鲁斯特、张爱玲、汪曾祺的长句，留意他们在哪里用逗号断开、主干放在哪里。
4. **论述去关联词实验**：把一段论述里的关联词全部删掉读一遍，再补回来，体会逻辑是怎么丢失的。
